# GaitLens — БЦС бар балалармен жұмыс істейтін дәрігерге арналған жүріс талдау көмекшісі

**AI-Sana Shakarim Solveathon: AI & Medicine-2026** · кейс: БЦС бар балалармен жұмыс істейтін дәрігерлерге арналған ЖИ-көмекші

GaitLens бір қатысушының **Baseline** (қалыпты жүріс), **Verbal** (вербалды кері байланыс) және **VR** (VR кері байланыс) кезіндегі жүріс параметрлерін салыстырып, өзгерістерді көрнекі түрде көрсетеді және дәрігерге дәлелді қорытынды дайындайды.

> **Негізгі қағида:** құрал диагноз қоймайды және ем тағайындамайды. ЖИ — ақпарат ұсынушы, шешімді әрқашан дәрігер қабылдайды. Әр тұжырымның жанында оның сандық негізі (мән, Δ, сенімділік интервалы, цикл саны `n`) көрсетіледі.

## Мүмкіндіктері

| Бөлім | Не істейді |
|---|---|
| 📋 Пациент картасы | Δ және Δ %, цикл саны `n`, Baseline-ға қатысты өзгеріс кестесі |
| 📊 Салыстыру | Көрсеткіш таңдау, бокс-плот және цикл бойынша график |
| 📈 Қисықтар | 5 айнымалының орташа ± SD қисығы, тұрақсыз (ерекшеленген) циклдерді белгілеу |
| 🧭 Өзгеріс детекторы | Бутстреп 95% сенімділік интервалы, эффект өлшемі d, «анықталды / анықталмады» |
| 👥 Когорта | 29 қатысушының GPS өзгерісі, жылу картасы, таңдалған қатысушының когорттағы орны |
| ⚙️ Ережелер | Дәрігер өз шектері мен хабарламаларын береді (JSON, локалды, код орындалмайды) |
| 📝 Қорытынды | Шаблон қорытынды, дәрігер ескертпесі, PDF / .md / .csv экспорты, ХФЖ (МКФ) b770 / d450 анықтамасы |
| 🤖 Модель сапасы | Random Forest + Leave-One-Subject-Out, метрикалар, шатасу матрицасы |
| 🧪 Деректер сапасы | Цикл саны, бос мәндер (NaN) үлесі |

Интерфейс, қорытынды және PDF есеп **үш тілде**: қазақша, орысша, ағылшынша (сол жақ тақтадан ауыстырылады).

## Іске қосу

**Талаптар:** Python 3.10 немесе жоғары (орнату кезінде «Add Python to PATH» белгісін қойыңыз).

```
cd GaitLens
pip install -r requirements.txt
streamlit run app.py
```

Windows-та екінші реттен бастап `Start_GaitLens.bat` файлын екі рет басу жеткілікті. Браузерде `http://localhost:8501` ашылады. Файл жүктемесеңіз, `sample_data/` ішіндегі деректер қолданылады.

## Деректер

`Discrete_Parameters_Baseline/Verbal/VR.csv` және (қалауы бойынша) `Kinematics_Kinetics_Baseline/Verbal/VR.csv`. Бөлгіш `;`, ондық белгі `,`, бос мәндер `NaN`. Файл атында `Baseline`, `Verbal` немесе `VR` болуы керек, жағдай атынан анықталады. Әр қатысушыда тек бір жақ (LEFT/RIGHT) жазылған. Бес-алты файлды бір мезгілде жүктеуге болады.

Жүктелген деректер (29 қатысушы): Baseline 866, Verbal 870, VR 870 цикл; Verbal/VR-да әр қатысушыға 30 цикл, Baseline-да 20–32 цикл.

## Әдістер (қысқаша)

- **Өзгеріс:** Δ = шарт орташасы − Baseline орташасы; Δ % тек оң мәнді көрсеткіштерге (нөлден өтетіндерге есептелмейді).
- **Сенімділік интервалы:** әр жағдай ішінде циклдерді қайта таңдау (бутстреп, 2000 қайталау, 95%). Интервал нөлді қамтымаса — «өзгеріс анықталды». Бұл статистикалық белгі, клиникалық маңыздылық емес.
- **Эффект өлшемі d:** орташа айырма / біріккен SD.
- **Тұрақсыз цикл:** цикл қисығының өз жағдайының медиана қисығынан RMS қашықтығы, робасты z (медиана және MAD) бойынша; шекті дәрігер слайдермен өзгертеді.
- **Когорта:** әр қатысушы өз Baseline-мен салыстырылады (бутстреп 95% ИН); шолу зерттеу сипатында, көптік салыстыруға түзету жоқ.
- **Модель:** Random Forest (150 ағаш), Leave-One-Subject-Out: бір қатысушының барлық циклдері не оқытуда, не тексеруде (кодта `assert` тексереді); бос мәндерді толтыру тек train бөлігінде үйретіледі. Метрикалар: accuracy, balanced accuracy, macro-F1, шатасу матрицасы, жұптық салыстыру.
- **Қорытынды мәтін:** шаблон, сандар кодтан алынады (ойдан сан жоқ). Ережелер — JSON деректер, `exec`/`eval` жоқ, рұқсат етілген өрістер ғана.

## Модель нәтижесі (ашық көрсетіледі)

| Тапсырма | Balanced accuracy | Кездейсоқ деңгей |
|---|---|---|
| Baseline / Verbal / VR (3 класс) | 0.418 | 0.333 |
| Baseline vs Verbal | 0.660 | 0.500 |
| Baseline vs VR | 0.629 | 0.500 |
| Verbal vs VR | 0.461 | 0.500 |

Мағынасы: жағдайдың жалпы «қолтаңбасы» әлсіз, әсер қатысушыдан қатысушыға әртүрлі. Сондықтан құралдың негізі — жеке өзгеріс есебі, ал модель ашық техникалық тексеріс ретінде қалдырылған.

## Шектеулер мен ескертулер

- Көрсеткіштердің мағынасы (мысалы, GPS/GVS «төмен = қалыпқа жақын») баған атауларына қарай жазылған; деректердің ресми сипаттамасымен растау керек. `aMinSagH`, `pctmZeroStSagH` үшін бағыт көрсетілмейді.
- Қисықтардағы момент бірлігі және `x` осі (0–100% қадам циклі) атауларынан болжанған.
- Когорта мен жұптық нәтижелер зерттеу сипатында (n=29), клиникалық қорытынды емес.
- Деректерде цикл тәртібі хронологиялық екені көрсетілмеген; цикл бойынша графикті уақыттық тренд ретінде оқымаңыз.
- ХФЖ (МКФ) кодтары анықтамалық: b770 «Жүріс үлгісінің функциялары»; d450 «Жүру» — тек контекст. Квалификаторлар берілмейді.
- Құрал медициналық бұйым емес, клиникалық шешімді ауыстырмайды.

## English summary

**GaitLens** compares gait parameters of one child across **Baseline**, **Verbal** feedback and **VR** feedback from the provided CSV files, visualises changes versus Baseline (with cycle counts and bootstrap 95% confidence intervals), flags unstable cycles, offers a cohort overview, lets the clinician define local rules (stored as JSON, never executed as code), and produces a PDF/Markdown/CSV report. The interface, summaries and PDF are available in Kazakh, Russian and English.

The tool does **not** diagnose or prescribe; the clinician decides. A subject-wise (Leave-One-Subject-Out) Random Forest is included with openly reported, modest metrics (balanced accuracy 0.42 vs 0.33 chance), supporting the design choice of individual change reports.

Run: `pip install -r requirements.txt` then `streamlit run app.py` (Windows: double-click `Start_GaitLens.bat`).
