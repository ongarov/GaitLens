==========================================================================
 GaitLens —  ІСКЕ ҚОСУ НҰСҚАУЛЫҒЫ (Windows)
==========================================================================

Бұл нұсқаулық жобаны басқа компьютерге көшіріп, нөлден іске қосуға арналған.
Ең қысқа жол: 1) Python орнату  2) кітапханаларды орнату  3) Start_GaitLens.bat.


--------------------------------------------------------------------------
  НЕ КЕРЕК
--------------------------------------------------------------------------
  - Windows 10 немесе 11.
  - GaitLens папкасы (немесе GaitLens.zip файлы).
  - ИНТЕРНЕТ: тек бірінші рет, кітапханаларды орнату үшін.
    Орнатылғаннан кейін қосымша интернетсіз жұмыс істейді.
  - Браузер (Chrome, Edge немесе Firefox).
  - Бос орын: шамамен 1 ГБ (Python мен кітапханалар үшін).


--------------------------------------------------------------------------
  ЖОБАНЫ КӨШІРУ
--------------------------------------------------------------------------
  1) GaitLens папкасын (не zip файлды) флешкаға, Google Drive-қа немесе
     Telegram-ға көшіріңіз.
  2) Жаңа ноутбукте Жұмыс үстеліне (Desktop) көшіріп алыңыз.
  3) Егер zip болса: файлды оң жақ батырмамен басып, "Extract All..."
     ("Барлығын шығару") таңдаңыз. Zip ішінде тұрып іске қоспаңыз!
  4) Шыққан папканың ішінде app.py, requirements.txt, core, assets
     көрінуі керек. Егер ішінде тағы бір GaitLens папкасы болса,
     соның ішіне кіріңіз.

  Папка жолында кириллица немесе бос орын болса да, әдетте жұмыс істейді,
  бірақ қиындық шықса, папканы C:\GaitLens деп атап, соған көшіріңіз.


--------------------------------------------------------------------------
  PYTHON ОРНАТУ (бір рет)
--------------------------------------------------------------------------
  Алдымен тексеріңіз: Win + R басып, cmd деп жазып Enter басыңыз. Қара
  терезеде:

      python --version

  - "Python 3.10", "3.11" немесе "3.12" шықса — орнатылған, 3-бөлімге өтіңіз.
  - Қате немесе нұсқа төмен болса — орнатыңыз:

  1) https://www.python.org/downloads/ сайтына кіріңіз.
  2) Python 3.12 (немесе 3.11) жүктеңіз. Ең жаңа нұсқаны емес, 3.11 / 3.12
     таңдаған сенімдірек: кітапханалардың дайын нұсқалары бар.
  3) Орнату терезесінің ЕҢ БАСЫНДА төмендегі белгіні МІНДЕТТІ қойыңыз:

        [x] Add python.exe to PATH

     Содан кейін "Install Now" басыңыз.
  4) Орнату біткен соң барлық қара терезені жауып, жаңадан ашыңыз және
     python --version командасын қайта тексеріңіз.


--------------------------------------------------------------------------
  КІТАПХАНАЛАРДЫ ОРНАТУ (бір рет, интернет керек)
--------------------------------------------------------------------------
  1) GaitLens папкасының ішінде (app.py көрінетін жерде) мекенжай жолағын
     басып, ішіндегіні өшіріп, cmd деп жазыңыз да Enter басыңыз.
     Қара терезе дәл осы папкада ашылады.
  2) Мынаны жазыңыз:

        pip install -r requirements.txt

     2–5 минут алады. Соңында "Successfully installed ..." шығады.
     "[notice] A new release of pip is available" деген жол — қате емес,
     елемей қоюға болады.

  Егер "'pip' is not recognized" шықса:

        python -m pip install -r requirements.txt


--------------------------------------------------------------------------
  ІСКЕ ҚОСУ
--------------------------------------------------------------------------
  Ең оңай жол:  Start_GaitLens.bat файлын екі рет басыңыз.

  Немесе қара терезеде (GaitLens папкасында тұрып):

        streamlit run app.py

  'streamlit' танылмаса:

        python -m streamlit run app.py

  Не болады:
  - Қара терезеде мәтін шығады, бірнеше секундтан соң браузерде
    http://localhost:8501 ашылады.
  - Бірінші рет Email сұраса, жай ENTER басыңыз.
  - Windows Брандмауэрі сұраса, "Allow access" ("Рұқсат ету") басыңыз.
  - ҚАРА ТЕРЕЗЕНІ ЖАППАҢЫЗ: жапсаңыз, қосымша тоқтайды.
  - Тоқтату: қара терезеде Ctrl + C.

  Браузер өзі ашылмаса, мекенжайды қолмен жазыңыз:  localhost:8501
